# Bot Train Power Start

A small Factorio mod that gives you a starter infinity chest for new games. It is designed to speed up early setup for bot, train, and power networks.

## Features

- Infinite starter chest with rails, signals, train stops, locomotives, and wagons
- Logistic and construction bots, roboports, and substations
- Logistic chests and combinators for early automation
- Optional Py replacement items when the Py mod is present

## Purpose

This mod helps you begin a run with the key building blocks already available, so you can set up logistics, rail lines, and power infrastructure much faster.

## Installation

1. Place this mod folder in your Factorio mod directory.
2. Launch Factorio and enable the mod in Mod Settings.
3. Start a new game and the chest will be created for the player.

## Compatibility

- Factorio 2.1
- Base game dependency
